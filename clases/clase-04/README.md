# Clase 4 - Programación lógica con Prolog

## Materiales

- [Guion docente](guion-docente-programacion-logica.md)
- [Actividad práctica](actividad-base-conocimiento-prolog.md)

## Propósito

Traducir las ideas de la IA simbólica a un programa declarativo ejecutable: representar un dominio con hechos y reglas, formular consultas e interpretar la inferencia de Prolog.

## Supuesto de implementación

La propuesta está diseñada para una clase de **120 minutos**, con una práctica de **50 minutos**, en grupos de 3 o 4 estudiantes. El guion incluye recortes sugeridos para una clase de 90 minutos.
