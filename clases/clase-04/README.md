# Clase 4 - Programación lógica con Prolog

Esta carpeta reúne los materiales para desarrollar la clase:

- [Guion docente](guion-docente-programacion-logica.md): secuencia de 120 minutos con explicaciones, ejemplos, preguntas y demostraciones.
- [Actividad](actividad-base-conocimiento-prolog.md): trabajo grupal de 45 minutos para modelar, consultar y auditar una base de conocimiento académica.

La clase retoma hechos, reglas e inferencia de la Clase 3 y los lleva a una forma ejecutable en Prolog. La secuencia cubre consultas, variables, unificación, múltiples soluciones, backtracking, mundo cerrado, aritmética y una primera regla recursiva.
