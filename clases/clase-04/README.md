# Clase 4 - Programación lógica con Prolog

Materiales para desarrollar la clase:

- [Guion docente](guion-programacion-logica.md): secuencia de 120 minutos, explicaciones, ejemplos, preguntas y cierre.
- [Actividad práctica](actividad-base-conocimiento.md): construcción y prueba de una base de conocimiento en Prolog.
- [Archivo inicial](actividad_base.pl): punto de partida para los grupos.

La clase traduce los conceptos de IA simbólica a una forma ejecutable: hechos, reglas, consultas, unificación y búsqueda de soluciones.
