# Clase 3 - IA simbólica

Esta carpeta reúne los materiales para desarrollar la clase:

- [Apunte](apunte-ia-simbolica.md): lectura previa o posterior a la explicación docente.
- [Actividad](actividad-sistema-experto.md): trabajo grupal para realizar durante la clase.
- [Hoja de ruta de lectura](hoja-ruta-lectura-russell-norvig.md): recorrido guiado por *Artificial Intelligence: A Modern Approach* con preguntas de opción múltiple.
- [Libro de referencia en Google Drive](https://drive.google.com/file/d/1xU008onWQF5dymFOgQXQw_KkjiB6vv5M/view?usp=sharing): PDF compartido por la cátedra para uso académico.
- [Clave docente de lectura](clave-docente-hoja-ruta.md): respuestas, justificaciones y criterios para validar la comprensión.

La secuencia sugerida es presentar primero símbolos, representación e inferencia; recorrer luego ventajas, límites y el caso MYCIN; finalmente, realizar la actividad grupal como puente hacia programación lógica y Prolog.
