# Clase 8 - Big Data y Machine Learning

Esta carpeta contiene:

- [Guion para estudiantes](guion-big-data-machine-learning.md): explicación de las 36 diapositivas, diccionario, correcciones técnicas y preguntas de comprensión.
- [Ejercicios de indagación y laboratorio](ejercicios-indagacion-laboratorio.md): actividades sobre literatura científica, documentación y repositorios de código.

## Resultados de aprendizaje

Al finalizar, los estudiantes deberían poder:

1. distinguir Big Data, análisis predictivo y Machine Learning;
2. describir un pipeline desde la fuente de datos hasta la decisión;
3. formular detección de fraude como clasificación desbalanceada;
4. interpretar falsos positivos, falsos negativos, precision y recall;
5. evaluar críticamente una afirmación técnica usando literatura, documentación y código reproducible.

## Advertencia sobre la presentación original

La diapositiva 36 usa regresión lineal y R² para fraude. Ese planteo no corresponde a clasificación binaria: el guion lo reemplaza conceptualmente por regresión logística y métricas de clasificación.
