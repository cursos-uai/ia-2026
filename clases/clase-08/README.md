# Clase 8 - Big Data y Machine Learning

Esta carpeta contiene materiales de apoyo para comprender la presentación de 36 diapositivas de la Unidad 4.

- [Guion para estudiantes](guion-big-data-machine-learning.md): diccionario, explicación diapositiva por diapositiva, correcciones técnicas y preguntas de autoevaluación.
- [Ejercicios de investigación y experimentación](ejercicios-investigacion-y-repositorios.md): actividades con artículos académicos, documentación oficial y repositorios públicos.

## Recorrido sugerido

1. Leer el guion hasta la diapositiva 17.
2. Resolver los ejercicios 1 y 2 para discutir las V de Big Data y la documentación de datasets.
3. Leer las diapositivas 18 a 28 y resolver el ejercicio 3 sobre arquitectura.
4. Leer las diapositivas 29 a 36 y realizar los ejercicios 4, 5 y 6.
5. Elegir uno de los desafíos de ampliación 7 u 8.

Los ejercicios privilegian la indagación y la reproducción de ejemplos mantenidos por sus comunidades originales. No hace falta completar todos en una única clase.
